Frequently asked

Is this legal? Am I scraping Shopify stores?

No scraping involved. Shopify exposes a public /products.json endpoint on every store - it's a documented feature, not a loophole. We access it exactly as a browser would. There are no legal restrictions on reading publicly accessible product data.

Which stores does it work on?

Any store running Shopify - regardless of theme, plan, or customisation. That's roughly 4.6 million stores worldwide. You just need the store's domain.

Will it get blocked or hit CAPTCHAs?

No. Because we use Shopify's own public API endpoint rather than scraping rendered pages, there are no blocks, CAPTCHAs, or anti-bot measures to deal with. It's the same data Shopify makes available to any browser.

How does change detection work?

Each run compares the current catalog against the previous run's data. Any product where the price, compare-at price, inventory status, or variant count changed gets flagged in the output. New products and removed products are also flagged.

Can I automate it to run daily without logging in?

Yes. Save your store list as an Apify Task and set a schedule. Results are automatically available for export, or connect via Zapier or Make to push changes to a spreadsheet or trigger a Slack notification when something moves.
