Questions

Frequently asked

Is this legal? Can I use building permit data commercially?

Yes. Building permit data is public record, published by city and county governments on official open data portals. We access it via official government APIs. There are no legal restrictions on commercial use of public permit data.

How fresh is the data?

Most cities update daily. A few update weekly. LA and Dallas are exceptions — LA is typically 12–24 months behind, and Dallas hasn't updated since January 2024. Data freshness is documented per city in the tool.

Does it include contractor contact details?

Most cities include contractor company name and license number. Some (Austin, Nashville) include a contact name. Phone numbers and emails are not in the permit data — you'll need to look those up separately using the contractor name and license.

Can I automate it to run without logging in every time?

Yes. Save your configuration as an Apify Task and set a schedule (daily, weekly, etc.). Results are automatically available for export, or you can connect via Zapier or Make to push data to your CRM automatically.

My city isn't on the list. Can you add it?

Any city running Socrata open data can be added via the custom endpoints feature — no code required, just the domain and dataset ID. If you need a city added to the built-in list, contact us at hello@handstands.io.
